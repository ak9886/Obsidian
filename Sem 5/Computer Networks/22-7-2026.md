# Switching Techniques
- Network switching is the process of forwarding data from one device to another within the same network or across networks using network switches.


- Switches read the MAC addresses of incoming data frames to determine the correct destination port, reducing unnecessary traffic and collisions.
- For communication outside the local network, switches forward data to routers, which then handle inter-network delivery.
## Categories:
*3 types:*
- Circuit-switched
- Packet-switched
	- Datagram Networks
	- Virtual-circuit networks
- Message-switched
### Circuit-Switched Network
- Physical connection between systems
- Switch can only turn the data stream on/off
- Three phases:
	- Connection Setup
	- Transmission
	- Termination
- In circuit switching, the resources need to be reserved during the setup phase; the resources remain dedicated for the entire duration of data transfer until the teardown phase
- In transmission phase, actual data communication takes place.
- Once the transmission is over, the resources has to be released in this phase.
- Circuit switching was very common in telephone networks in the past, although part of the telephone network today is a packet-switched network
