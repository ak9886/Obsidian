# Formal Languages & Automata (FLA) – Regular Expression Cheat Sheet

> **Alphabet:** Σ = {a, b}

## Symbols

| Symbol | Name | Meaning | Example |
|--------|------|---------|---------|
| `a`, `b` | Literal | Matches the symbol itself | `a` matches only `a` |
| `ε` | Empty String | String of length 0 | `ε` |
| `∅` | Empty Language | Contains no strings | `∅` |
| `|` or `+` | Union (OR) | Either expression | `a \| b` |
| Concatenation | AND THEN | Expressions written together | `ab` = `a` followed by `b` |
| `*` | Kleene Star | Zero or more repetitions | `a*` |
| `+` (unary, if supported) | Kleene Plus | One or more repetitions | `a+` |
| `?` | Optional | Zero or one occurrence | `a?` |
| `()` | Grouping | Groups expressions | `(ab)*` |

---

# Operator Precedence

1. `*`, `+` (Kleene Plus), `?`
2. Concatenation
3. Union (`|` or binary `+`)

Example:

```regex
ab|c
```

is interpreted as:

```text
(ab)|c
```

NOT

```text
a(b|c)
```

# Difference Between `ε` and `∅`

| Symbol | Meaning |
|--------|---------|
| `ε` | Empty string (length = 0) |
| `∅` | Empty language (contains no strings) |

Examples:

```
L = {ε}
```

Contains **one** string.

```
L = ∅
```

Contains **zero** strings.

# Quick Exam Cheat Sheet

| Requirement | Regular Expression |
|-------------|--------------------|
| Any string | `(a\|b)*` |
| Only `a`s | `a*` |
| Only `b`s | `b*` |
| Starts with `a` | `a(a\|b)*` |
| Ends with `a` | `(a\|b)*a` |
| Starts & ends with `a` | `a(a\|b)*a` |
| Contains `ab` | `(a\|b)*ab(a\|b)*` |
| Exactly one `a` | `b*ab*` |
| At least one `a` | `(a\|b)*a(a\|b)*` |
| At most one `a` | `b*(ab*)?` |
| Empty string | `ε` |
| Empty language | `∅` |

## Exam Tips (SRM)

- `*` means **0 or more** occurrences.
- `+` may mean **union** in SRM notation—check your faculty's convention.
- Concatenation has **higher precedence** than union.
- Regular expressions describe **languages**, which are usually **infinite** unless otherwise specified.
- You are **not** expected to enumerate every string; the regex itself represents the entire language.
