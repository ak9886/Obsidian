| Name of the Formula                              | Formula                                                                                                              | Description                                                                                                                            |
| ------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| **Iteration Method (Fixed Point)**               | $$\huge x_{n+1} = g(x_n)$$                                                                                           | Used to find a fixed point of \(g(x)\), corresponding to a root of \(f(x)=0\). Convergence condition: $$\huge$$                        |
| **Bisection Method**                             | $$\huge x_r = \frac{x_l + x_u}{2}$$                                                                                  | Requires a continuous function on \([x_l,x_u]\) and: $$\huge f(x_l)\cdot f(x_u) < 0$$ Always converges, but slowly.                    |
| **Method of False Position (Regula Falsi)**      | $$\huge x_r = x_u - \frac{f(x_u)(x_l - x_u)}{f(x_l)-f(x_u)}$$                                                        | Uses a secant line instead of midpoint approximation. Requires: $$\huge f(x_l)\cdot f(x_u) < 0$$ Usually faster than Bisection.        |
| **Newton-Raphson Method**                        | $$\huge x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)}$$                                                                     | Requires differentiability near the root and: $$\huge f'(x_n)\neq0$$ Converges very quickly if the initial guess is close.             |
| **Gauss Elimination Method (Pivot Operation)**   | $$\huge a_{ij}^{(k)} = a_{ij}^{(k-1)} - \frac{a_{ik}^{(k-1)}}{a_{kk}^{(k-1)}}a_{kj}^{(k-1)}$$                        | Converts the coefficient matrix into upper triangular form during forward elimination.                                                 |
| **Gauss Elimination Method (Back Substitution)** | $$\huge x_i = \frac{b_i - \sum_{j=i+1}^{n} a_{ij}x_j}{a_{ii}}$$                                                      | Solves variables starting from the final row after elimination. Requires: $$\huge a_{kk}\neq0$$                                        |
| **Gauss Jordan Method (Normalization)**          | $$\huge a_{kj} = \frac{a_{kj}}{a_{kk}}$$                                                                             | Normalizes the pivot row so the pivot element becomes 1.                                                                               |
| **Gauss Jordan Method (Elimination)**            | $$\huge a_{ij} = a_{ij} - a_{ik}\cdot a_{kj} \quad (i\neq k)$$                                                       | Eliminates all other entries in the pivot column to reduce the matrix to identity form.                                                |
| **Jacobi Method**                                | $$\huge x_i^{(k+1)} = \frac{1}{a_{ii}}\left(b_i - \sum_{\substack{j=1 \\ j\neq i}}^{n} a_{ij}x_j^{(k)}\right)$$      | Uses only previous iteration values. Requires a strictly diagonally dominant or symmetric positive definite matrix for convergence.    |
| **Gauss-Seidel Method**                          | $$\huge x_i^{(k+1)} = \frac{1}{a_{ii}}\left(b_i - \sum_{j<i} a_{ij}x_j^{(k+1)} - \sum_{j>i} a_{ij}x_j^{(k)}\right)$$ | Uses updated values immediately, so it generally converges faster than Jacobi. Requires diagonal dominance for guaranteed convergence. |
