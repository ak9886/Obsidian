#Maths 

| Name of the Formula                     | Formula                                                                                                                                                                               | Variables Used                                                                                                                                           | Description of Conditions                                                                                                                                                       |
| --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Iteration Method (Fixed Point)          | $$x_{n+1} = g(x_n)$$                                                                                                                                                                  | - $(x_{n+1}$): New approximation of the root - $(x_n)$: Current approximation of the root - $(g(x))$: Rearranged form of $(f(x)=0)$ such that $(x=g(x)$) | Used to find a fixed point of (g(x)), corresponding to a root of (f(x)=0). For convergence: $$                                                                                  |
| Bisection Method                        | $$x_r = \frac{x_l + x_u}{2}$$                                                                                                                                                         | - $(x_r)$: Midpoint (new root approximation) - $(x_l)$: Lower bound - $(x_u)$: Upper bound - ($f(x)$): Continuous function                               | Requires: 1. ($f(x)$) continuous on ([x_l, x_u]) 2. Root bracketed such that: $$f(x_l)\cdot f(x_u) < 0$$ Robust and always converges, but slowly.                               |
| Method of False Position (Regula Falsi) | $$x_r = x_u - \frac{f(x_u)(x_l - x_u)}{f(x_l)-f(x_u)}$$                                                                                                                               | - $(x_r)$: New root estimate - $(x_l, x_u)$: Interval bounds - ($f(x_l), f(x_u))$: Function values at bounds                                             | Requires a continuous function and a bracketing interval: $$f(x_l)\cdot f(x_u) < 0$$ Usually faster than Bisection when the function is nearly linear near the root.            |
| Newton-Raphson Method                   | $$x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)}$$                                                                                                                                            | - $(x_{n+1}$): Next approximation - $(x_n)$: Current approximation - ($f(x_n)$): Function value - $(f'(x_n)):$ Derivative value                          | Requires the function to be differentiable and continuous near the root. Also: $$f'(x_n)\neq0$$ Converges quadratically if the initial guess is close to the true root.         |
| Gauss Elimination Method                | Pivot Operation: $$a_{ij}^{(k)} = a_{ij}^{(k-1)} - \frac{a_{ik}^{(k-1)}}{a_{kk}^{(k-1)}}a_{kj}^{(k-1)}$$ Back Substitution: $$x_i = \frac{b_i - \sum_{j=i+1}^{n} a_{ij}x_j}{a_{ii}}$$ | - ($a_{ij}$): Matrix coefficients - $(b_i)$: Constant vector elements - ($k,i,j$): Indices - ($n$): Number of equations                                  | Converts the matrix into upper triangular form, then solves by back substitution. Requires non-zero pivot elements: $$a_{kk}\neq0$$ If zero occurs, partial pivoting is needed. |
| Gauss Jordan Method                     | $$a_{kj} = \frac{a_{kj}}{a_{kk}}$$ $$a_{ij} = a_{ij} - a_{ik}\cdot a_{kj} \quad (i\neq k)$$                                                                                           | - ($a_{kj}$): Pivot row element - ($a_{kk}$): Pivot element - ($a_{ij}$): Target element                                                                 | Reduces the matrix directly to identity form, removing the need for back substitution. Requires: $$a_{kk}\neq0$$ More computationally expensive than Gauss Elimination.         |
| Jacobi Method                           | $$x_i^{(k+1)} = \frac{1}{a_{ii}}\left(b_i - \sum_{\substack{j=1 \ j\neq i}}^{n} a_{ij}x_j^{(k)}\right)$$                                                                              | - ($x_i^{(k+1)}$): New value of ($x_i$) - ($x_j^{(k)}$): Previous iteration values - ($a_{ij}$): Matrix coefficients - ($b_i$): Constants                | Convergence generally requires the matrix to be: - Strictly diagonally dominant, or - Symmetric positive definite. Uses only previous iteration values.                         |
| Gauss-Seidel Method                     | $$x_i^{(k+1)} = \frac{1}{a_{ii}}\left(b_i - \sum_{j<i} a_{ij}x_j^{(k+1)} - \sum_{j>i} a_{ij}x_j^{(k)}\right)$$                                                                        | - ($x_i^{(k+1)}$): Updated value - $(x_j^{(k+1)}$): Newly updated values - ($x_j^{(k)}$): Old values - ($a_{ij}$): Matrix coefficients                   | Faster convergence than Jacobi because updated values are reused immediately. Requires diagonal dominance or symmetric positive definiteness for guaranteed convergence.        |
