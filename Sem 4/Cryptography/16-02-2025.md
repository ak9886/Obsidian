# AES Encryption Method
- The first rounds consist of four distinct transformation functions:
	- `SubBytes`
	- `ShiftRows`
	- `MixColumns`
	- `AddRoundKey`
- The final round contains only 3 transformations (`AddRoundKey`) before the first round, consider as round 0.
- Each transformation takes one or more `4X4` matrices as input and produces a `4X4` matrix as output.
- Key expansion function generates `N+1` round keys
4X4 matrix = 16 elements = 16 words
## MixColumns
When a fixed matrix is there, there is <u>fixed column</u> that the first matrix is multiplied against. <u>ONLY THE SENDER AND RECIEVER KNOW THE FIXED COLUMN</u>.
