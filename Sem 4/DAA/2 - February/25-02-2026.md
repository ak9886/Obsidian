# Huffman Coding
When a message is sent, it should not be sent as plain text. It should be encrypted. If, for example 'a' is replaced with a '%' every time, then over time, the message could successfully be decrypted by threat actors. If the character 'a' is converted to its ASCII value, 65, it is a little better encrypted. Huffman Coding proposes a new system of encryption by using the frequencies of the letters as well. For example:
EXAMPLE: 'AABBC'
Unique Letters: 'ABC'
Frequencies:
- A : 2
- B : 2
- C : 1
With this set of frequencies of letters, we can get 2<sup>3</sup> combinations, so for example, we can put:
- A : 2 (2000)
- B : 2 (2001)
- C : 1 (1010)
