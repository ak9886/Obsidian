# Huffman Coding
When a message is sent, it should not be sent as plain text. It should be encrypted. If, for example 'a' is replaced with a '%' every time, then over time, the message could successfully be decrypted by threat actors. If the character 'a' is converted to its ASCII value, 65, it is a little better encrypted. Huffman Coding proposes a new system of encryption by using the frequencies of the letters as well.
