# Floyd - Washand

There is a path from a to b and a to c. there is also a path from c to d.

Our task is to reduce the path constants to something other than infinity (which it gets categorized into by default if there <u>isn't</u> a direct path to it. For example, a to d is not given a dedicated path, so it gets resolved to infinity automatically).
