# Minimum Spanning Tree & Tree Traversal
## What is a Tree?
- It is a subset of edges connected with vertices
G = (V,E)
Example: Social Media -> We can convert social media into graphs
A graph usually has equal amounts of edges and vertices, while trees having n vertices will have (n-1) edges. Also graphs are cyclic, i.e., they can start and end at the beginning. [A-> B -> C -> D -> A]
Trees will always have (n-1) edges when there are n vertices.

## What is a Minimum Spanning Tree [MST]?
if we have a cyclic graph in the shape of a square with the vertices A,B,C and D in such a way that A -> B -> C -> D -> A, we can make 4 different types of trees by removing one edge for each possibility.
Let's add some weights to this graph
e<sub>1</sub> = 2
e<sub>2</sub> = 3
e<sub>3</sub> = 4
e<sub>4</sub> = 2
So, now we have weights to use in our edges. A minimum spanning tree is the one that has the least value when the weights of the edges are all added together. This formula can be used to find the shortest distance on the Global Positioning System (GPS)
