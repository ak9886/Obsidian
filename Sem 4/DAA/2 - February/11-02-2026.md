# Difference b/w Quick and Insertion Sort
## Quick Sort

- We can divide the runtimes
- At the first runtime, the last number in the set is considered <b><u>the pivot</u></b>, which then it compares it to the previous element, and so on, iterating backwards.

# Insertion Sort

- Time complexity = n<sup>2</sup>.
- Happens in a nested `for` loop.
- In the second layer of the `for` loop, swapping will be performed.
- When a bigger number is before a smaller number, the numbers "swap" places, allowing it to be sorted.


# Pseudocode
```Pseudocode
QuickSort(A,Start, end)
{
	if (start < end)
	{
		Problem = Partition(A, Start, End)
		QuickSort(A, Start,Problem-1)
		QuickSort(A, Problem+1, end)
	}
}
```

```Pseudocode
Partition(A, Start, end){
	Pivot = A(end)
	preindex = start
	for i = Start to end-1
	{
		if (A(i)<=Pivot)
		{
			Swap(a(i), P(preindex))
			preindex = preindex+1
		}
	}
	Swap(A(preindex), a(end))
	return preindex
}
```

# Maximum Subarray Summation
## Maximum Subarray Summation

The **Maximum Subarray Summation** problem asks:

> Given an array of integers (positive, negative, or zero), find the **contiguous subarray** that has the largest possible sum, and return that sum.

---

### 🔎 What does “contiguous subarray” mean?

It means the elements must be next to each other in the array.  
You cannot skip elements.

Example array:

```
[−2, 1, −3, 4, −1, 2, 1, −5, 4]
```

Some valid subarrays:

- `[4, −1, 2, 1]` ✅
    
- `[1, −3, 4]` ✅
    
- `[1, 4, 2]` ❌ (not contiguous)
    

---

## 🎯 Goal

From all possible contiguous subarrays, find the one with the **maximum total sum**.

For the example above:

Best subarray:

```
[4, −1, 2, 1]
```

Sum:

```
4 + (−1) + 2 + 1 = 6
```

So the answer is:

```
6
```

---

## 🧠 Why Is This Important?

This problem appears in:

- Dynamic Programming
    
- Stock profit analysis
    
- Signal processing
    
- Financial data analysis
    
- Competitive programming
    

It’s one of the most famous algorithm problems.

---

## 🚀 Efficient Solution: Kadane’s Algorithm

Instead of checking all subarrays (which takes **O(n²)** time), we use **Kadane’s Algorithm**, which runs in:

```
O(n) time
O(1) space
```

### 💡 Core Idea

At each position:

- Either extend the previous subarray
    
- Or start a new subarray from current element
    

### Formula:

```
current_sum = max(arr[i], current_sum + arr[i])
max_sum = max(max_sum, current_sum)
```

---

## 🧮 Step-by-Step Example

Array:

```
[-2, 1, -3, 4, -1, 2, 1, -5, 4]
```

We keep updating:

|Element|Current Sum|Max Sum|
|---|---|---|
|-2|-2|-2|
|1|1|1|
|-3|-2|1|
|4|4|4|
|-1|3|4|
|2|5|5|
|1|6|6|
|-5|1|6|
|4|5|6|

Final Answer:

```
6
```

---

## 🧩 Edge Case

If all numbers are negative:

Example:

```
[-5, -2, -8]
```

Answer:

```
-2
```

(Because the largest single element is the maximum subarray.)

---

## 🔥 Variations

1. Return the actual subarray (not just sum)
    
2. Circular maximum subarray
    
3. 2D maximum submatrix
    
4. At most K elements
    

---

## 📌 Final Definition

Maximum Subarray Summation =  
The **largest possible sum of a contiguous portion of an array**.
