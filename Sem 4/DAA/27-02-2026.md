# Huffman Coding
Char    Repeat
a       5
b       9
c       12
d       13
e       16
f       45
Add the repetitions together, we get 90. If we use the standard 8-bit encryption system, then we get $8*90 = 720$ bits of data
We can however, decrease the that value to 270 bits of data using Huffman Coding.
