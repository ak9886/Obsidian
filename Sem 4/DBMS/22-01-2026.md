# DBMS Architecture
- Frontend: User Programs, User Interface, Admin Tools, Query Tools
- Query Processor:  application program object code, compiler and linker, DML Queries, DDL Interpreter, DML Compiler and organizer
- Storage Manager: Buffer Manager, File Manager, Transaction Manager
- The cylinder: Files, Indices, Data Dictionart
