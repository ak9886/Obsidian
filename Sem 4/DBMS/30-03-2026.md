# Multivalued Dependency and Fourth Normal Form
## Definition: A Relation Schema R is in 4NF with respect to a set of dependencies F (that includes functional deps. and multivalued deps.) if, for every _nontrivial_ multivaled dependency X ->-> Y in F<sup>+17</sup> X is a super-key for R.
We can state the following points:
- An all-key relation is always in BCNF since it has no FDs.
- An all-key relation such as the EMP relation in Figure 15.15(a) which has no FDs but has the MVD Ename -->-> Pname | Dname, is not in 4NF.
- A relation that is not in 4NF due to a nontrivial MVD must be decomposed to convert it into a set of relations in 4NF.
## Example: 
### (a) EMP
Columns: Ename{Smith, Smith, Smith, Smith, Smith}, Pname{X,Y,X,Y}, Dname{John, Anna, John, Anna}
### (b) EMP_PROJECTS
Columns: Ename{Smith, Smith}, Pname{X,Y}
