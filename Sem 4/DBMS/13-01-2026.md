# File Processing System
When the computer was invented, we started figuring how to  store data.
**Question 1:** Why do we need to store data on the computer?
**Question 2:** What are the devices that can store data?
**Question 3:** What are the formats that you can use to store data
**Question 4:** What are the different data storage models


**ANSWERS:**
Computers store data to retain files, programs, and operating systems permanently even when powered off, unlike temporary RAM. This ensures large-capacity retention for software installation, file organization, and protection against loss from hardware failures or disasters. Proper storage also enables data recovery, security, and analysis for decision-making

## Storage Devices

Devices for storing data fall into categories like magnetic, flash-based, optical, and network-attached options. Common examples include hard disk drives (HDDs) for high-capacity bulk storage, solid-state drives (SSDs) for faster access, USB flash drives and SD cards for portability, CDs/DVDs/Blu-ray for optical media, and cloud or external drives for remote access.

## Data Formats

Data can be stored in various file formats suited to different uses, such as structured text or binary efficiency. Popular formats include CSV for simple tabular data, JSON and XML for hierarchical or web data, Parquet for compressed big data analytics, Excel for spreadsheets, and database-specific ones like SQLite DB or Access ACCDB.
## Storage Models

Data storage models organize information for specific workloads, such as row-oriented for transactions or column-oriented for analytics. Key types include N-Ary Storage Model (NSM or row-store) for fast inserts/updates in OLTP, Decomposition Storage Model (DSM or column-store) for query scans in OLAP, NoSQL variants like key-value, document, column-family, and graph stores, plus broader systems like relational databases, data lakes, and distributed file systems.

# Introduction to DBMS
## DBMS stands for **Database Management System**
- A DBMS is a collection of interrelated data and a set of programs that are used to access the data
- The collection of data, usually referred to as the database, contains information relevant to an enterprise.
- The primary goal of a DBMS to provide a way to store and retrieve database information that is both convenient and efficient.
## Need for DBMS:
- Database systems are developed to deal huge amount of data.
- Data to be stored and retrieved for data processing in an  effective manner.
