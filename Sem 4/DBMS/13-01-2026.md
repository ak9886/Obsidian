# File Processing System
When the computer was invented, we started figuring how to  store data.
**Question 1:** Why do we need to store data on the computer?
**Question 2:** What are the devices that can store data?
**Question 3:** What are the formats that you can use to store data
**Question 4:** What are the different data storage models


**ANSWERS:**
Computers store data to retain files, programs, and operating systems permanently even when powered off, unlike temporary RAM. This ensures large-capacity retention for software installation, file organization, and protection against loss from hardware failures or disasters. Proper storage also enables data recovery, security, and analysis for decision-making.hp+2​

## Storage Devices

Devices for storing data fall into categories like magnetic, flash-based, optical, and network-attached options. Common examples include hard disk drives (HDDs) for high-capacity bulk storage, solid-state drives (SSDs) for faster access, USB flash drives and SD cards for portability, CDs/DVDs/Blu-ray for optical media, and cloud or external drives for remote access.vedantu+2​

## Data Formats

Data can be stored in various file formats suited to different uses, such as structured text or binary efficiency. Popular formats include CSV for simple tabular data, JSON and XML for hierarchical or web data, Parquet for compressed big data analytics, Excel for spreadsheets, and database-specific ones like SQLite DB or Access ACCDB.reddit+2​

## Storage Models

Data storage models organize information for specific workloads, such as row-oriented for transactions or column-oriented for analytics. Key types include N-Ary Storage Model (NSM or row-store) for fast inserts/updates in OLTP, Decomposition Storage Model (DSM or column-store) for query scans in OLAP, NoSQL variants like key-value, document, column-family, and graph stores, plus broader systems like relational databases, data lakes, and distributed file systems.sciencedirect+4​
