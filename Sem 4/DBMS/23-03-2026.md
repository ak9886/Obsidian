# Types of Functional Dependencies
1) Functional Dependency (Trivial)
	- When Y is a subset of X
	- Example: (Student_ID, Name) -> Name
2) Non-Trivial Functional Dependency
	- When Y is **<u>not</u>** a subset of X
	- Example: Student_ID -> Name
3) Fully Functional Dependency
	- When Y depends on the whole of X
	- Example: Student_ID  Course  Marks(Student_ID, Course) -> Marks
4) Partial Dependency
	- When Y depends on only part of a composite key
	- Example: (Student_ID, Course) -> Name (Name depends on only on Student_ID)
5) Transitive Dependency
	- When X -> Y and Y -> Z, then X -> Z
	- Example: Student_ID -> Department, Department -> HOD, then Student_ID -> HOD (transitive)
