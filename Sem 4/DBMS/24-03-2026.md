## 1st Normal Form (1NF)
### Rule:
- All attributes must have an atomic value(no multi-valued or composite attributes)
### Methods:
- Add a Separate Table
- Add multiple columns


# Example: Multivalued Attributes
The Columns in the Table are:
- emp_id: 1,2,3
- emp_name: John Tick, Darth Trader, Rony Stark
- emp_mobile: 99999957773, 8888853337, 77777720008
- emp_skills: Python, JavaScript; HTML, CSS, JavaScript; Java, Linux, C++

### Test whether Table is in 1NF? [Yes/No]
No, as emp_skills is a multi-valued columns. There are 2 possible solutions for this:
- Create 2 seperate tables; \
	- one with:
		- emp_id, emp_name, and emp_mobile
	- and then another tables with:
		- emp_id (as a foreign key), and emp_skills
- Or make a table with no primary keys, where the emp_id, emp_name and emp_mobile are repeated multiple times to accommodate the emp_skills.
