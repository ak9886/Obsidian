# Obsidian — Personal Knowledge Vault

A personal **Obsidian vault** for organising university notes, cybersecurity learning, technical projects, research, assignments, and day-to-day knowledge in one searchable workspace.

This repository is the Git-backed copy of the vault. It contains Markdown notes alongside supporting files and Obsidian configuration, so it can be explored directly on GitHub or opened locally in Obsidian.

## What's Inside

- **University Coursework** — Semester-organised notes, course materials, lab experiments, and assignments.
- **Cybersecurity** — Penetration-testing references, CTF material, security notes, and write-up templates.
- **Technical Knowledge** — Software engineering, algorithms, AI/LLM notes, and development references.
- **Personal Knowledge & Journals** — Dated notes, reflections, and general-purpose pages.
- **Visual Notes & Diagrams** — Excalidraw files and other supporting assets.
- **Vault Configuration** — Obsidian settings and community-plugin configuration stored under `.obsidian/`.

## Repository Structure

| Path | Purpose |
|---|---|
| `Sem 3/`, `Sem 4/`, `Sem 5/` | Semester-wise academic materials |
| `Excalidraw/` | Visual notes and diagrams |
| `pages/` | Knowledge pages and topic notes |
| `journals/` | Journal entries |
| `assets/` | Images and supporting files |
| `.obsidian/` | Obsidian workspace settings and plugin configuration |
| `Master_Penetration_Testing_Playbook_v2.md` | Consolidated penetration-testing reference |
| `Assignment *.md`, `Experiment *.md` | Assignment and laboratory documentation |

Individual files may also be stored at the vault root for quick access, drafts, or standalone references.
