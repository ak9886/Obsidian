### Notes on Topic Recurrence Separated by Unit

#### Unit 1: Introduction 15 Hour

This unit focuses on the foundational programming concepts in C, the definition of data structures, Abstract Data Types (ADT), and complexity analysis.

|Topic Category|Notes on Recurrence and Detail|Percentage of Questions|
|:--|:--|:--|
|**Programming in C (Structures, Pointers, Memory)**|Questions frequently test **Dynamic Memory Allocation** using functions like `malloc()` and `calloc()`. Concepts of C array initialization and access methods are also tested. Detailed descriptive questions address **Self-referential structures** and their use in implementing dynamic data structures.|**18.5%**|
|**Algorithm Complexity**|Analysis of efficiency is critical. Questions involve calculating the **asymptotic time complexity** for given code segments (e.g., using Tabular methods). There are conceptual questions on how mathematical notations (Big O, etc.) are used to measure complexity, and identifying scenarios for asymptotic analysis. The study guide marks **Time and space complexity** as **"Very important"**.||
|**Data Structure and ADT**|Definitional questions covering **Abstract Data Types (ADT)** and their role in implementation are recurrent. Questions may also require suggesting a suitable ADT for a real-world system.||
|**Arrays / Matrix**|Basic array access methods and the definition or algorithm for **Matrix multiplication** appear.||

#### Unit 2: List Structure 15 Hour

This unit covers lists, their different implementations (Array, Linked), types (Singly, Doubly, Circular), and specialized applications.

|Topic Category|Notes on Recurrence and Detail|Percentage of Questions|
|:--|:--|:--|
|**Linked List Implementation & Operations**|This is the highest recurring single unit. Questions test basic understanding of linked list structure creation and specific operations like inserting a node at the end. Comparisons highlighting the trade-offs (e.g., space utilization, insertion/deletion speed) between linked lists and other structures are present.|**25.9%**|
|**Linked List Types (Circular, Doubly)**|Properties of **circular linked lists** are tested. The practical application and benefits (e.g., ease of navigation) of a **doubly linked list** are asked. The use of linked lists to model sequences (like train compartments) appears in descriptive sections.||
|**List Applications**|Two major applications recur: **Sparse Matrix** representation and the algorithm for performing **Polynomial Arithmetic** using linked lists. The study guide identifies Polynomial and Arithmetic operations as **"very important"**.||
|**Array Implementation**|Descriptive questions may require algorithms for basic array operations (e.g., insertion, deletion, finding maximums in 2D arrays), linking back to the array implementation of a list ADT.||

#### Unit 3: Stack and Queue 15 Hour

This unit focuses on linear data structures defined by access constraints (LIFO/FIFO), their implementations, and critical applications.

|Topic Category|Notes on Recurrence and Detail|Percentage of Questions|
|:--|:--|:--|
|**Expression Conversion & Evaluation**|This is highly recurrent and mandatory for descriptive sections. Questions require converting **Infix to Postfix** and evaluating postfix expressions. The study guide marks **Infix to postfix conversion** as **"Very important"**.|**24.1%**|
|**Stack ADT & Applications**|Questions cover the definition and principles of LIFO. Applications tested include using stacks to check for **balanced parenthesis** and general applications/limitations of the stack structure (e.g., which task stacks cannot be used for). Descriptive questions cover implementing **Push and Pop operations using linked lists**.||
|**Queue ADT & Operations**|Questions assess the understanding of the **FIFO principle**. Scenarios requiring the tracking of element order after multiple enqueue/dequeue operations are common. Implementation details, such as implementing a Queue using a linked list, are tested in descriptive answers.||
|**Combined Operations**|Objective questions frequently test complex scenarios involving the combined operation of elements being pushed onto a stack and then dequeued from a queue.||

#### Unit 4: Trees and Hashing 15 Hour

This unit covers non-linear hierarchical structures (Trees) and direct access methods (Hashing).

|Topic Category|Notes on Recurrence and Detail|Percentage of Questions|
|:--|:--|:--|
|**Binary Search Trees (BST) & Balanced Trees**|Questions require algorithms for **inserting and deleting** elements in a BST. Conceptual questions compare **BST with AVL trees** and defining properties of balanced trees. Knowledge of specific balanced trees like the **B-Tree** (e.g., calculating maximum keys) is necessary.|**24.1%**|
|**Hashing and Collision Handling**|This topic appears consistently in both objective and descriptive parts. Questions cover the definition of a **hash table** and detailed methods of **Collision Avoidance/Resolution**, requiring explanations or application of techniques like **Separate Chaining, Linear Probing, and Double Hashing**.||
|**Tree Traversal and Definitions**|Basic tree definitions, such as a **Full Binary Tree**, and practical application of traversal methods (e.g., determining Pre-order or In-order traversal from a diagram) are tested.||

#### Unit 5: Graph 15 Hour

This unit focuses on non-linear networked structures, traversal techniques, and key optimization algorithms.

|Topic Category|Notes on Recurrence and Detail|Percentage of Questions|
|:--|:--|:--|
|**Minimum Spanning Tree (MST) Algorithms**|Finding the MST is a mandatory descriptive topic. Questions require illustrating or applying **Kruskal's Algorithm** or identifying the suitable algorithm (Kruskal's or Prim's) to find the MST in a connected graph. The concept of drawing and identifying spanning trees is also tested.|**20.4%**|
|**Shortest Path Algorithms**|**Dijkstra's Algorithm** is highly recurrent. Questions require applying the algorithm to find the shortest path between nodes and identifying the type of problem it solves (All-pair vs. Single-source shortest path). The study guide marks **Dijkstra's algorithm** as **"Very important"**.||
|**Graph Traversal & Representation**|Questions assess knowledge of graph properties (like vertex degree). Traversal concepts, particularly related to **Breadth-First Traversal (BFS)** and distance properties, appear. Representing a graph using an **Adjacency Matrix** (e.g., determining the number of zeros) is also tested.||
